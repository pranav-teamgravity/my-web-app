# Privacy Policy for WebGravity

**Effective Date:** [Insert Date]

Thank you for using **WebGravity**. This Privacy Policy explains how information is handled when you use our mobile application. WebGravity is a mobile view of the Gravity website and acts only as a browser interface to display the website content.

---

## 1. Introduction

WebGravity is a WebView-based mobile application that loads the official Gravity website.
The application itself does **not** collect, store, or share any personal data. All user interactions occur directly on the Gravity website and are governed by the website’s own policies.

---

## 2. Information Collection

### a. Data Collected by WebGravity

The WebGravity app:

* Does **not** collect any personal information
* Does **not** require user accounts
* Does **not** track user behavior
* Does **not** store cookies, passwords, or form data

### b. Data Collected by the Gravity Website

If you enter any information on the Gravity website (such as login details, forms, or profile data), that information is processed solely by the Gravity website. WebGravity has no access to or control over that data.

Please refer to the official Gravity website privacy policy for details on how the website handles your information.

---

## 3. App Permissions

WebGravity only uses minimal permissions required to display the website:

* Internet access to load web content
* Network state access to detect connectivity

The app does **not** request access to location, contacts, camera, microphone, storage, or any other sensitive user data.

---

## 4. Third-Party Services

WebGravity does not include any analytics, advertisements, or tracking tools.
Any third-party services present on the Gravity website (such as ads, analytics, or login providers) are controlled by the website and not by this app.

---

## 5. Security

All communication happens directly between your device and the Gravity website using secure web protocols. WebGravity does not intercept, store, or modify any user data.

---

## 6. Children’s Privacy

WebGravity does not knowingly collect personal information from children. Any data submitted on the Gravity website is subject to the website’s own privacy practices.
